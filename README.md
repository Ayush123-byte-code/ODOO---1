![Traveloop Banner](https://images.unsplash.com/photo-1507525428034-b723cf961d3e)

---

## 📌 Project Overview

Traveloop is a responsive travel planning web application that helps users organize and manage trips efficiently.

Users can:
- Create personalized trips
- Add destinations
- Manage itineraries
- Track budgets
- Maintain packing checklists
- Store travel notes

Built using:
- Python
- Django
- HTML
- CSS
- Bootstrap
- JavaScript
- MySQL

# ⚙️ Installation

## 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/traveloop.git
```

---

## 2️⃣ Open Project

```bash
cd traveloop
```

---

## 3️⃣ Install Django

```bash
python -m pip install django
```

---

## 4️⃣ Install MySQL Connector

```bash
python -m pip install pymysql
```

---

## 5️⃣ Run Server

```bash
python manage.py runserver
```
